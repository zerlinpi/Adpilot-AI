## Key finding: table-set relationships

- **`ddl/` and `migration/` define an identical set of 99 tables.** There is no table present in one but not the other.
- **`init_mysql.sql` is a superset of the PostgreSQL sources.** Every one of the 99 PostgreSQL tables is present in `init_mysql.sql`, PLUS 4 additional tables not in the PG `ddl/migration`:
  - `cash_flow`
  - `receivables`
  - `payables`
  - `customer_tickets`
- Therefore, for the **103-table** `init_mysql.sql`, there are **zero PostgreSQL `ddl/migration` tables absent from it**.

## DML / seed files for V2 consolidation (task 2.4)

Two parallel seed sources exist; they use **different column conventions**:

1. **`init_mysql.sql` seed block (PREFERRED — entity-aligned, MySQL syntax).** Uses `INSERT IGNORE` and entity-aligned column names. Seeds **50 tables**:
   `ad_groups, ai_model_call_logs, approval_requests, audit_logs, automation_policies, buyer_messages, campaigns, cash_flow, competitor_products, customer_reviews, customer_tickets, data_quality_issues, data_scopes, departments, feishu_integrations, goals, import_jobs, inventory_forecasts, inventory_snapshots, keyword_insights, keywords, listing_contents, marketplaces, negative_keywords, operation_tasks, orders, organizations, payables, permissions, platform_connections, product_upload_jobs, products, receivables, recommendations, refunds, replenishment_plans, replenishment_requests, reports, returns, role_permissions, roles, search_terms, settlements, stores, suppliers, user_departments, user_roles, users, warehouse_inventory, warehouse_locations`

2. **`dml/001..014_*.sql` (LEGACY — PostgreSQL syntax, legacy column/table names).** Uses `ON CONFLICT DO NOTHING`. Targets some tables/columns that DO NOT match the entities, including:
   - `suppliers (name, email, ...)` — legacy; entities use `supplier_name` / `contact_email`.
   - `warehouses (...)` and `warehouse_inventory (warehouse_id, quantity, reserved_quantity, available_quantity)` — legacy; entities use `warehouse_locations` and `warehouse_inventory(warehouse_location_id, quantity_on_hand, quantity_reserved, quantity_available)`.
   - `reviews (...)` — legacy; entity-aligned name is `customer_reviews`.
   - `purchase_requests (...)` — the only source providing column shape for this table.

   ⚠️ **Do not copy legacy DML column names verbatim into V2.** Prefer the `init_mysql.sql` seed block; pull only `purchase_requests` (and any genuinely missing seed) from the legacy DML, remapping to entity-aligned column names.
